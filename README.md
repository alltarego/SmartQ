# SmartQ

Sistema inteligente de gerenciamento de filas utilizando Web, Mobile e IoT.

## Tecnologias

- HTML / CSS / JavaScript
- Node.js
- Express
- MySQL
- Flutter
- Arduino UNO
- ESP32
- OLED

## Estrutura

- backend: API e regras de negócio
- web: aplicação web
- mobile: aplicativo Flutter
- iot: dispositivos IoT
- docs: documentação
